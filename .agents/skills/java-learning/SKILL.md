# Java Learning

1. 현재 구현의 개념(예: DI, JPA, 트랜잭션)을 3~5문장으로 설명한다.
2. 관련 코드 경로를 안내한다.
3. 사용자가 먼저 구현하도록 작은 과제와 입출력 예시를 제시한다.
4. 요청 시 힌트를 순차 제공한다.
5. 제출된 코드의 정합성, 예외, 테스트를 피드백한다.
6. 사용자가 완성 코드를 요청한 경우에만 전체 구현을 제시한다.
